# Монтажные скиллы — установка и шпаргалка

Полная инструкция по установке и решению проблем — в [README.md](README.md). Коротко:

```bash
git clone https://github.com/elianoraMullagalieva/design-montazh-so-vkusom.git
cd design-montazh-so-vkusom && ./install.sh
```

Windows: `powershell -ExecutionPolicy Bypass -File .\install.ps1`. Без git — скачай ZIP, распакуй и запусти тот же скрипт.

Установщик сам копирует скиллы в `~/.claude/skills/` и ставит ffmpeg, playwright + Chromium и whisper (mlx-whisper на Apple Silicon, faster-whisper на остальных). Шрифты и скрипты рендера отдельно копировать **не нужно** — они лежат внутри папок скиллов.

## Монтажные скиллы

| Скилл | Что делает | Что лежит внутри |
|---|---|---|
| `montazh-prozrachnaya-tipografika` ⭐ | Прозрачный субтитр-монтаж поверх говорящего видео: Bebas + Gogol + оранжевый акцент, синхрон по словам, экспорт ProRes с альфой | `etalon/` (эталонный HTML), `fonts/`, `record_v.py`, `record_alpha2.py`, `shotn.py` |
| `premium-motion-infographics` ⭐ | Дорогая смысловая SVG/HTML-инфографика: визуальный план, отдельный объект и движение на каждый смысл, QA | `references/` |
| `eli-reels-graphics` | Графика-подложка 1080×1920 за говорящей головой: жёсткая типо-шкала, SVG-анимации | `template.html`, `fonts/`, `record.py` |
| `montazh-zagolovok-rvanyi` | «Заголовок + рваный»: крупное вступление и мелкие пословные субтитры по краям | `references/reference.md` |
| `reels-infografika` | SVG-инфографика 1080×1040 над говорящей головой в стиле бренда | шаблон, шрифты, скрипты |
| `svg-animations`, `svg-creator` | SVG-графика и анимации | примеры и скрипт превью |

Скрипты рендера после установки лежат здесь:

```bash
python3 ~/.claude/skills/montazh-prozrachnaya-tipografika/record_v.py      --html ролик.html --out ролик.mp4 --duration 45   # mp4 на чёрном (режим Screen)
python3 ~/.claude/skills/montazh-prozrachnaya-tipografika/record_alpha2.py --html ролик.html --out ролик.mov --duration 45   # ProRes 4444 с прозрачностью
python3 ~/.claude/skills/montazh-prozrachnaya-tipografika/shotn.py         --html ролик.html 0 3 6 9                        # снимки сцен без рендера
python3 ~/.claude/skills/eli-reels-graphics/record.py                      --html кусок.html --out кусок.mp4 --duration 8
```

Эталонные ролики и видео-примеры — в `extras/etalony-html/`, коллекция шрифтов — в `extras/fonts/`.

## Как этим пользоваться

1. Записываешь говорящее видео.
2. Говоришь Claude: **«сделай субтитр-монтаж поверх этого видео»** + путь к файлу.
3. Claude транскрибирует речь по словам → раскладывает типографику → показывает HTML в браузере.
4. Смотришь, даёшь правки живьём.
5. Утверждаешь → Claude рендерит прозрачный `.mov` (или mp4 на чёрном для режима «Экран»).
6. Кидаешь на дорожку в CapCut: у `.mov` фон уже прозрачный, mp4 — режим смешивания «Экран».

## Важные правила

- **Прозрачный оверлей = фон строго пустой.** Никаких полупрозрачных фоновых сеток/дымки — при экспорте они дают мусор-точки на весь кадр.
- **Не перезаписывай файл, который уже нарезан** в монтаже — это рушит таймлайн. Новая версия = новое имя.
- Всё подробно расписано в `skills/montazh-prozrachnaya-tipografika/SKILL.md` — Claude читает это сам.
- Bebas Neue Cyrillic и Gogol: лицензии не подтверждены — для коммерческих проектов проверь права или используй Manrope / JetBrains Mono (OFL-1.1).
