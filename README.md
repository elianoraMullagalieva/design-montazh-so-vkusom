# 🎬🎨 Дизайн и монтаж со вкусом

Практическая библиотека скиллов для Claude Code: дизайн интерфейсов, SVG и моушен, Reels-монтаж, типографика и безопасный набор шрифтов.

## Что внутри

- `skills/montage-svg-typography` — SVG-анимация, визуальные подложки для Reels, кинетическая типографика, монтаж и инфографика.
- `skills/design-ui` — арт-дирекция, UI/UX, дизайн-системы, типографика, интерфейсные стили и редизайн.
- `fonts/commercial-safe` — Manrope и JetBrains Mono с лицензиями SIL Open Font License 1.1. Их можно использовать в коммерческих проектах при соблюдении файлов лицензий.

В репозиторий не вошли личные проектные файлы, рабочие пути и шрифты с неподтверждёнными правами распространения.

## Как установить скилл

1. Скачай репозиторий: **Code → Download ZIP**.
2. Открой Claude Code.
3. Перетащи нужную папку скилла в чат или укажи путь к ней.
4. Напиши: «Установи этот скилл и используй его в работе».

Для коммерческого проекта перед использованием любого внешнего ассета или шрифта всегда отдельно проверь лицензию и права распространения.
